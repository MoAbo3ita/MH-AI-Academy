# تركيب سكربت التسجيل الجديد (Google Apps Script v2)

الموقع بعد التحديث **يعمل بالسكربت القديم أيضًا**، لكن بالسكربت الجديد تحصل على:
- تأكيد حقيقي لنجاح الحفظ (بدل افتراض النجاح).
- منع تسجيل نفس الطالب مرتين.
- حفظ رقم ولي الأمر.
- إشعار على إيميلك عند كل تسجيل (اختياري).

## الخطوات (5 دقائق)
1. افتح Google Sheet الخاص بالتسجيلات ← **Extensions (الإضافات) ← Apps Script**.
2. **انسخ السكربت الحالي كنسخة احتياطية** (احفظه في ملف نصي) قبل أي تغيير.
3. امسح الكود القديم والصق محتوى `Code.gs`.
4. (اختياري) اكتب إيميلك في `OWNER_EMAIL` أعلى الملف.
5. اضغط **Deploy (نشر) ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy**.
   - تأكد أن **Execute as: Me** و **Who has access: Anyone**.
   - رابط `/exec` يبقى كما هو، فلا تحتاج لتغيير `script.js`. (إن أنشأت نشرًا جديدًا برابط مختلف، انسخ الرابط الجديد في `APPS_SCRIPT_URL` داخل `public/script.js`.)
6. وافق على الصلاحيات عند الطلب (الشيت + الإيميل).

## ملاحظات مهمة
- السكربت يكتب في ورقة اسمها `Registrations` ويُنشئها تلقائيًا. لو عندك ورقة قديمة بأعمدة مختلفة، سيبدأ الجديد ورقة جديدة منفصلة، فانقل البيانات القديمة يدويًا لو أردت.
- **اختبر بعد التركيب:** سجّل رقمًا تجريبيًا من الموقع وتأكد من ظهور الصف في الشيت، ثم سجّل نفس الرقم والصف مرة ثانية وتأكد أنه لم يتكرر (ستظهر للطالب رسالة "أنت مسجّل بالفعل").
